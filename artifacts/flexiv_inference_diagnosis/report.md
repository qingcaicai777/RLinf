# Flexiv 接近动作偏离排查

这次排查比较 connecter_1010 在训练数据和已保存在线图像上的输出，检查模型动作是否能持续接近物体。没有启动机器人控制或验证真机跟踪。

## 输入与执行路径

当前 joint_absolute 配置使用 8 维 state（左臂 7 个实测关节角和夹爪宽度）、两路 RGB 图像、8 维绝对 action 和匹配的 norm stats。动作直接送入左臂 SendJointPosition，不经过手动拖动的 XY 方向映射。保存于 2026-10-10 17:10 的在线初始图像与 episode_000000 的初始图像接近；它不一定属于用户最新失败运行。没有发现字段、RGB 顺序或关节单位不匹配的证据。

## 模型输出与保持当前位置基准

沿用 40 个 episode 各 10 个观测、每次预测 32 步的离线结果。所有数值都是逐关节绝对角度误差的平均值；保持当前位置基准在所有未来步使用该观测的实测关节角。

| 样本 | 模型 chunk MAE | 保持当前位置 chunk MAE |
| --- | --- | --- |
| 400 个观测 | 0.361° | 0.759° |
| 40 个 episode 的起始观测 | 0.281° | 0.289° |

起始观测的第一步模型 MAE 为 0.184°，保持当前位置为 0.017°。起始示范第一步多数还未移动；所以首步方向与示范不一致不能单独用于判断接近方向，但证明小的绝对 MAE 不能证明启动阶段拟合充分。起始 chunk 的第 19 步，模型平均 q6 变化为 +0.130°，示范为 +0.405°；q7 分别为 +0.176° 与 -0.154°，表明各关节组合仍存在偏差。

## 输入变化对动作的影响

用 episode_000000 初始图像或保存的在线初始图像，分别搭配该训练帧实测 state 或配置里的 Home state，使用 3 个相同随机种子，对每组输入复用相同初始 noise。Home state 的夹爪宽度假设为 0.06 m，并非当时机器人的实测状态。

| 输入 | 对该示范 chunk 的关节 MAE | 第 19 步 q6 相对输入 state 的平均变化 |
| --- | --- | --- |
| 训练图像 + 训练 state | 0.506° | +0.382° |
| 训练图像 + 配置 Home state | 0.621° | +0.003° |
| 在线图像 + 训练 state | 0.584° | +0.009° |
| 在线图像 + 配置 Home state | 0.727° | -0.539° |

只换图像导致预测平均变化 0.149°；只换 state 导致平均变化 0.172°。这证明起始输出对输入变化敏感，不能据此重建真实失败运行或认定 Home 是根因。

## 末端位置误差的估算

使用本地 Rizon4 URDF，并从每个观测的 q 和实测 TCP 反推该观测的工具变换，估算预测 action 和示范 action 的末端位置差。反推工具平移的样本标准差小于 0.8 mm。该计算使用名义几何参数，没有使用机器人的标定模型，也不是实际执行的轨迹。

400 个观测的完整 chunk 位置误差平均约 5.68 mm，95 分位 13.41 mm；40 个起始观测平均约 4.02 mm。毫米级横向误差和姿态偏差可能影响抓取，并使后续观测离开示范分布。

## 尚需实际输入与跟踪证据

当前证据支持模型起始动作偏差和闭环误差累积这一候选原因。没有最新失败运行的实测 q、下发目标和 RTC/交接日志，因此尚不能确认模型、控制器跟踪、RTC 各自的贡献。

机器人端 capture-dir 现在同时保存每次图像对应的 observation.json，包含 state、TCP、prompt、动作类型和上一次关节目标。joint request tracking 日志同时包含实测 q 与上一次目标 q。用下一次失败运行的匹配观测离线推理，并比较实际跟踪误差，才能确定修正位置。


## 继续排查：基础模型、RTC 和 q6 编码边界

用户新增日志显示：tick 288 最大目标跟踪误差为 0.0463°；q6 实测 0.90051 rad、目标 0.90049 rad。全训练集 q6 实测最小值为 0.95464 rad，该观测已经低于训练范围约 3.10°。这一时刻机器人跟随了偏离训练分布的目标；不能用此日志排除所有时间点的跟踪误差。tick 292 的 deadline miss 出现在人工接管及控制模式切换之后。

### 同噪声 RTC 对照

使用 10 步去噪、每 16 帧请求、16 步剩余 overlap、4 步 delay、Jacobian 权重 10。在 0～320 帧的 21 次请求中，对各模式复用相同初始噪声。

| 输入方式 | 无 RTC | Jacobian RTC |
| --- | --- | --- |
| 每次输入训练集对应帧图像和实测 state，chunk 关节 MAE | 0.351° | 0.364° |
| 固定旧在线初始图像，初始 state 使用配置 Home，随后 state 假设完美跟随已执行目标，q6 最小目标 | 0.89075 rad | 0.89849 rad |
| 上述固定图像实验第一次未引导预测的第 15 步 q6 目标 | 0.95355 rad | 0.95355 rad |

逐帧训练观测实验中，第 15 步目标在无 RTC 和 Jacobian RTC 两条路径间平均只差 0.0277°，最大差 0.2868°。固定图像反馈实验说明不用 RTC 也能产生 q6 向低值漂移，因此 RTC 不是该实验漂移的必要条件。固定图像与完美跟踪是假设，不能作为真实运动轨迹或最新失败运行的复现。数据在 rtc_drift_experiment.json。

### q6 状态量化越界

该检查点 state.q01[5] 为 0.965023527 rad，配置 Home.q6 为 0.963757813 rad。按实际 quantile normalization，Home.q6 归一化约 -1.00579；当前 PI0.5 tokenizer 使用 digitize([-1,1]) - 1，所有低于 -1 的值都成为同一状态编码 -1。PI0.5 的 q6 状态通过离散 prompt 输入，因此无法靠该状态通道区分 q6=0.9638、0.9546 或 0.9005 rad；图像和其他关节仍会影响预测。这是现有训练/推理编码的性质，没有证据证明二者编码实现不同。

保持其他 Home 关节角、夹爪宽度和旧在线初始图像不变，按 3 个相同种子比较，仅改变输入 q6：

| 输入 q6 | 状态编码 | 第 15 步平均目标 q6 | 相对输入变化 |
| --- | --- | --- | --- |
| 0.954642 rad | -1 | 0.953590 rad | -0.060° |
| 0.963758 rad | -1 | 0.953590 rad | -0.583° |
| 0.965024 rad | 0 | 0.964316 rad | -0.041° |
| 0.967444 rad | 1 | 0.968440 rad | +0.057° |
| 0.980000 rad | 8 | 0.987655 rad | +0.439° |

0.954642 与 0.963758 两组在每个种子上都输出相同 q6 目标。这明确验证了该状态编码信息丢失及模型对编码边界的敏感性。40 个 episode 的首帧 q6 中位数为 0.965662 rad，13 个首帧低于 q01，说明低编码并非完全未出现在训练集中，不能单独认定低编码必然失败。实际启动 q6 可能在 Home 容差内变化；尚无最新运行的匹配初始观测，不能断定实际首帧恰好采用配置目标值。

当前可确认基础模型能在该近 Home 输入组合上首先产生向训练范围外的目标；在 q6 已越界后，离散 state 还丢失了偏离幅度的信息。这支持起始输入敏感与闭环恢复能力不足这一原因。对实际运行，应优先核对首帧 state 与对应图像，再评估与训练首帧的差异。没有修改状态编码、clamp 预测关节或改变 Home，以免改变训练语义或未经验证的控制行为。
